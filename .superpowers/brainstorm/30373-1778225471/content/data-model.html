Data Model — Entity Relationships

4 张核心表，覆盖用户、面试、对话和评分

Entity Relationship Diagram
user
id: INT PK
username: VARCHAR(50)
email: VARCHAR(255)
password_hash: VARCHAR(255)
created_at: DATETIME
1 → N
interview
id: INT PK
user_id: INT FK
position: VARCHAR(100)
resume_text: TEXT
status: ENUM('ongoing','done')
overall_score: INT
created_at: DATETIME
interview 1 → N
message
id: INT PK
interview_id: INT FK
role: ENUM('interviewer','user')
content: TEXT
question_number: INT
created_at: DATETIME
1 → 1
interview 1 → 1
evaluation
id: INT PK
interview_id: INT FK
overall_score: INT
categories: JSON
strengths: TEXT
weaknesses: TEXT
resume_suggestions: TEXT
created_at: DATETIME

Key Design Decisions

Resume stored once

解析后的纯文本存入 interview.resume_text，每次面试一份

Messages as question-answer pairs

interviewer 和 user 消息交替存储，question_number 追踪进度

Evaluation separate

评分独立于消息，categories 用 JSON 存各维度分数，方便扩展
